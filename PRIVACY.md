# Política de Privacidade - Ofertas e Achadinhos

Este aplicativo/serviço tem como finalidade exclusiva a automação e publicação de Pins de ofertas e recomendações de produtos no Pinterest.

### 1. Coleta de Informações
O aplicativo utiliza credenciais e tokens da API do Pinterest exclusivamente para criar e agendar Pins em pastas autorizadas pelo proprietário da conta. Não são coletados, armazenados ou compartilhados dados pessoais de terceiros ou visitantes.

### 2. Uso da API do Pinterest
A integração é realizada em conformidade com as diretrizes para desenvolvedores do Pinterest, utilizando os escopos mínimos necessários para publicação de conteúdo (pins:write, boards:read).

### 3. Contato
Para dúvidas ou informações sobre o aplicativo, entre em contato através do repositório oficial no GitHub.
